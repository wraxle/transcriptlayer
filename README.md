# TranscriptLayer clients

Official command-line, TypeScript, and Python clients for the TranscriptLayer API.

- CLI: `@wraxle/transcriptlayer-cli`
- TypeScript: `@wraxle/transcriptlayer`
- Python: `transcriptlayer`

The first beta is `0.1.0-beta.1` on npm and `0.1.0b1` on PyPI. See each package README for installation and usage.
